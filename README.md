# SOLhub_v2

SOL Hub Get Key page : un bouton **Get Key** qui redirige vers un lien aléatoire parmi 5. La page est responsive (mobile et PC).

La page comprend une barre de navigation en haut, une section « How it works », des cartes de fonctionnalités, la liste des executors, une FAQ et un pied de page.

## Fichiers

- `index.html` : la structure de la page
- `style.css` : les styles (responsive)
- `script.js` : la logique du bouton et la liste des 5 liens

## Utilisation

Ouvrez `index.html` dans un navigateur, ou publiez le dossier sur n'importe quel hébergement statique (GitHub Pages par exemple).

Pour changer les liens, modifiez le tableau en haut de `script.js` (ce sont volontairement des liens d'exemple, de `https://example.com/key1` à `key5`).
